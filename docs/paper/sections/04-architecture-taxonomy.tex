\section{Architecture Taxonomy and Implementation}
\label{sec:architecture-taxonomy}

\subsection{Attention and Sequence-Mixer Families}
\label{sec:attention-families}

The system implements fifty-six sequence mixers organized into nine functional categories that reflect how each method balances expressivity, computational cost, and memory.
\begin{enumerate}[leftmargin=*]
    \item \textbf{Dense baselines} (6): standard softmax attention, sigmoid attention, Continuum Attention, Grouped-Query Attention (GQA), Exclusive Self Attention (XSA), and Multi-Token Attention (MTA) provide full global routing at quadratic cost. XSA keeps the standard softmax block and strips the component of each head's output along the token's own value vector \citep{zhai_exclusive_2026}, a parameter-free exclusion that sharpens the division of labor between attention and the feed-forward path.
    \item \textbf{Recurrent and retentive} (3): RetNet, Mamba, and ODE-style blocks maintain state for constant-time inference through recurrence, selective state spaces, or continuous depth.
    \item \textbf{Sparse patterns} (11): Sparse Transformer, Longformer, SWA with attention sinks, BigBird, SparseK, NSA, SpargeAttn, FASA, MSA, SparDA, and LSA reduce quadratic cost through structured sparsity, token selection, training-free pruning, or semantic key clustering.
    \item \textbf{Gated mechanisms} (9): GLA, DeltaNet, Gated DeltaNet, Gated DeltaNet-2, HGRN2, FoX, Gated Softmax, KDA, and First Passage Attention (FPA) introduce data-dependent control over retention, forgetting, and update strength.
    \item \textbf{Latent compression} (13): MLA, GQLA, MLRA, Tucker, KPA, TPA, MFA, IHA, GTA, MTLA, CCA, CCGQA, and GMA compress key--value state into low-rank bottlenecks or route through a Gaussian-mixture latent memory.
    \item \textbf{Memory} (3): Titans pairs a local attention window with a surprise-driven associative memory updated at test time, Engram provides test-time read/write memory through learned N-gram hash lookups, and Memory Attention replaces the dedicated value projection with a layer-specific token-ID table.
    \item \textbf{Fast-weight attention} (6): Falcon-1/2/3 and Falcon-1A/2A/3A treat the recurrent state transition as an online continual-learning rule \citep{zhang_falcon_2026}.
    \item \textbf{Geometric field} (1): SSOG applies a structured geometric prior over the attention matrix \citep{pisoni_ssog_2026}.
    \item \textbf{Convolution-augmented} (2): the Conformer block \citep{Gulati2020} fuses multi-head self-attention with a depthwise-convolution module between two Macaron feed-forward layers, giving every layer a local branch alongside the global receptive field; Fast Conformer \citep{rekesh_fastconformer_2023} keeps that design for long-form speech and replaces global self-attention with a limited local window plus a head-pinned global token (Appendix~\ref{sec:annex-conformer}).
\end{enumerate}

\subsection{Dense and Recurrent Families}
The dense baselines---standard softmax \citep{vaswani_attention_2017}, sigmoid attention \citep{ramapuram_theory_2024}, and Continuum Attention \citep{khadangi_continuum_2026}, which replaces the softmax with exact integration of an exponential relevance density over piecewise-linear key/value trajectories---and the recurrent family---RetNet \citep{sun_retentive_2023}, Mamba \citep{gu_mamba_2023}, and ODE-style blocks \citep{zhang_continuous_2021}---define the expressiveness-versus-efficiency trade-off. Formulations, parallel and recurrent forms, pseudocode, and a comparison table are collected in Appendix~\ref{sec:annex-transformer}.

\subsection{Memory Family}
\label{sec:memory-family}
The memory family groups three mechanisms that add storage beside the attention
operator. Titans \citep{behrouz_titans_2025} runs dense attention over a local
window while a surprise-driven associative memory is updated at test time; this
repository implements the attention window only, and the neural-memory module is
not part of the implementation. Engram \citep{cheng2026conditionalmemoryscalablelookup}
retrieves N-gram embeddings through per-order hash tables and gates them into
the residual stream. Memory Attention \citep{kang_memory_attention_2026} keeps
the standard softmax attention operator but removes the dedicated value
projection: values are the contextual keys plus a layer-specific,
token-ID-indexed memory row, \(V = K + \mathrm{Norm}(E[s])\), with RoPE applied
only to the scoring pair. It increases parameter capacity without proportional
dense computation and retains a conventional KV cache at inference.

\subsection{Latent and Low-Rank Attention Family}
This family compresses per-token key--value state into a low-rank latent: MLA, GQLA, MLRA, Tucker, KPA, TPA, MFA, IHA, GTA, and MTLA unify grouped-query, latent, Kronecker- and CP-factorized, and temporal designs. CCA and CCGQA formulate attention in a compressed latent with decoupled grouping, while GMA replaces pairwise interaction with probabilistic routing through learned Gaussian-mixture components. Formulations, pseudocode, and a comparison table are collected in Appendix~\ref{sec:annex-latent}.

\subsection{Sparse Attention Extensions}
The registry includes twelve sparse blocks \citep{child_sparse_transformer_2019,beltagy_longformer_2020,jolicoeur_sliding_window_2026,zaheer_bigbird_2020,lou_sparsek_2024,yuan_nsa_2025,zhang_spargeattn_2025,wang_fasa_2026,lai_minimax_2026,fu_sparda_2026,kubicek_lsa_2026,wu_deep_sparse_conformer_2022}. Two inference-time methods, \texttt{fasa} and \texttt{sparge}, apply their sparse heuristic only when the model is in evaluation mode: during training the enclosing hybrid layer substitutes standard dense attention over the same $\mathbf{q}/\mathbf{k}/\mathbf{v}/\mathbf{o}$ projections, so the trained weights are exactly the ones the sparse path reads at inference. \texttt{swa} is also training-free but is a normal trainable mixer, so it runs its windowed pattern in both training and inference. LSA is the family's semantic selector: keys are pooled and Ward-clustered per 512-token block, and each query scores the cached bucket centroids instead of every key, selecting top-$p$ buckets that expand into its $k$ long-range keys on top of sinks and a one-block window. ProbSparse \citep{wu_deep_sparse_conformer_2022,zhou_informer_2021} inverts the axis: it ranks queries with a max--mean approximation of the KL divergence against the uniform distribution over a sampled key subset and scores only the top-$u = c_2\lceil\ln L\rceil$ dominant ones, which brings the layer to $\mathcal{O}(L\log L)$ for long bidirectional encoders while leaving decoding dense. Formulations, pseudocode, per-block characteristics, and a comparison table are collected in Appendix~\ref{sec:annex-sparse}.

\subsection{Gated and Fast-Weight Attention}
The gated family contains nine blocks \citep{yang_gla_2023,yang_deltanet_2024,yang_gated_deltanet_2024,hatamizadeh_gated_deltanet2_2026,qin_hgrn2_2024,lin_forgetting_transformer_2025,qiu_gated_attention_2025,kimi_kda_2025,liu_first_passage_2026}. Gating controls what information survives, either in recurrent state updates (GLA, DeltaNet variants, HGRN2, KDA) or in the full attention path (FoX, Gated Softmax, FPA). FPA replaces the path sum of a forget gate with a range minimum of a learned field, so a later token can erase newer keys while preserving older ones: the alive keys form a stack, and FoX is its non-rising-walk special case. Formulations, pseudocode, and a comparison table are collected in Appendix~\ref{sec:annex-gated}.

Fast-weight attention recasts the recurrent update as an online continual-learning rule; the six Falcon variants \citep{zhang_falcon_2026} unify DeltaNet-style regression and linear-attention writes under read-after-write semantics with normalized step sizes and explicit forgetting. Each variant ships a recurrent reference scan and a chunk-parallel kernel. Formulations, configuration knobs, and published results are collected in Appendix~\ref{sec:annex-fast-weight}.
