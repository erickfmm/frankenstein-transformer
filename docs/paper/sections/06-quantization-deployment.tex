\section{Quantization and Deployment}
\label{sec:quantization}

The deploy stage converts a trained checkpoint into a deployment artifact through post-training quantization. BitNet-style ternary packing \citep{wang_bitnet_2023} is complemented by two block-affine formats and a ternary safetensors format, all emitted inside a self-contained HuggingFace package whose only weight container is \texttt{model.safetensors}. In the block-affine formats, weights are grouped into blocks of 32: \texttt{Q8\_0} stores one FP16 scale and 32 signed 8-bit values per block (8.5 bits per weight), whereas \texttt{Q4\_0} stores one FP16 scale and 16 packed nibbles (4.5 bits per weight). The ternary \texttt{i2\_s} layout packs four symbols per byte and adds one FP32 scale per tensor (2 bits per weight before the scale). These formats complement, rather than replace, the native standard and quantized artifacts and the BitNet GGUF export used by external runtimes.

The safetensors artifact supports two load-time runtimes. In the \emph{dequantize-on-load} runtime (v1), packed blocks are expanded to FP32 parameters while the model is loaded, so inference executes exactly like the unquantized backbone. In the \emph{packed-linear} runtime (v2), each quantized projection keeps its packed buffers and dequantizes inside \texttt{forward}; when a projection replaces a BitLinear layer, the input LayerNorm and INT8 activation quantization are preserved. Only two-dimensional linear weights whose last dimension is a multiple of 32 are quantized; embeddings, normalization parameters, biases and convolutions remain in FP32, which bounds the achievable compression ratio. The experiment harness exports \texttt{Q8\_0}, \texttt{Q4\_0} and \texttt{i2\_s} in both runtimes and reports their task accuracy alongside the unquantized export. The formulations, block layouts and size estimates are deferred to Appendix~\ref{sec:annex-bitnet}.
